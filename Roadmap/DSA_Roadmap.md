# DSA in Python - Complete Roadmap

Pehle Ek Baat Samajh

**Data Structure** = "Data ko kaise store karein"
**Algorithm** = "Us data pe kaam kaise karein"

Dono ek saath chalte hain — pehle DS sikhte hain, phir uske Algorithm.

---

## Step-by-Step Roadmap

### ✅ STEP 1 — Python Basics Pakka Karo (2-3 weeks)

Pehle yeh sab aana chahiye:

- Lists, Tuples, Dictionaries, Sets
- Functions, Loops, Conditions
- OOP (Classes & Objects) — bahut zaroori hai DSA ke liye
- Time & Space Complexity ka basic idea (Big O Notation)

> 💡 Agar yeh sab aata hai toh directly Step 2 pe ja

---

### ✅ STEP 2 — Basic Data Structures (4-5 weeks)

Yeh order follow kar:

| # | Data Structure | Uske Saath Algorithm |
|---|----------------|----------------------|
| 1 | Array / List | Searching, Sorting |
| 2 | String | Pattern matching |
| 3 | Stack | Bracket matching, Undo feature |
| 4 | Queue | BFS, Scheduling |
| 5 | HashMap / Dict | Frequency count, Two-sum |
| 6 | Linked List | Traversal, Reverse |

> 💡 **Trick:** Pehle DS samajh, phir turant usi DS ka algorithm practice kar. Ek saath!

---

### ✅ STEP 3 — Basic Algorithms (3-4 weeks)

| Algorithm | Kya Seekhega |
|-----------|--------------|
| Binary Search | Sorted array mein fast dhundna |
| Bubble/Selection/Insertion Sort | Sorting basics |
| Merge Sort / Quick Sort | Fast sorting |
| Two Pointer | Array problems |
| Sliding Window | Subarray problems |

---

### ✅ STEP 4 — Advanced Data Structures (4-5 weeks)

| # | Data Structure | Uske Saath Algorithm |
|---|----------------|----------------------|
| 1 | Tree / Binary Tree | Inorder, Preorder, Postorder |
| 2 | BST | Insert, Delete, Search |
| 3 | Heap / Priority Queue | Top K elements |
| 4 | Graph | BFS, DFS |
| 5 | Trie | Word search |

---

### ✅ STEP 5 — Advanced Algorithms (5-6 weeks)

| Algorithm | Kab Use Hota Hai |
|-----------|-----------------|
| Recursion + Backtracking | Maze, N-Queens |
| Dynamic Programming (DP) | Optimization problems |
| Greedy | Best choice at each step |
| Divide & Conquer | Big problem → small problems |

---

## Sabse Zaroori Formula 🔑

```
Ek DS Seekha
    ↓
Usi DS pe 10-15 Problems Solve Karo (LeetCode Easy)
    ↓
Algorithm Seekha Jo Us DS Pe Kaam Karta Hai
    ↓
5-10 Medium Problems Solve Karo
    ↓
Agla DS Lo
```
